# ActiveForge Model Card

作者：晨星 · 版本：v0.1.0 · 质量等级：S

## 1. 用途

**预期用途**
- 标注预算受限场景下的**池式主动学习**实验与策略选型基准：给定大量未标注样本 + 少量已标注种子，迭代选择最有价值的样本请求标注。
- 适用任务：表格 / 低维向量的**分类**问题（二分类与多分类均已验证）。
- 典型应用：医学影像标注、文本标注、工业缺陷检测标注等「标注贵、未标注多」的场景。

**不适用场景**
- 数据流式到达、无法做池式选择的场景（本系统为 pool-based，非 stream-based）。
- 回归 / 序列标注 / 目标检测（当前仅实现分类）。
- 需要在线预训练权重的场景（本系统零下载设计，不含深度表征）。

## 2. 数据

| 来源 | 说明 |
|------|------|
| `gaussian2d` | 合成：两团重叠高斯（sep=1.2），线性边界 |
| `moons` | 合成：双月牙（noise=0.40），非线性边界 |
| `blobs20` | 合成：20 维 3 类（class_sep=1.0），含信息/冗余特征 |
| `spiral` | 合成：双螺旋（noise=0.12），强非线性稠密边界 |
| `digits700` | sklearn 内置手写数字，分层子采样 700（CPU 预算控制） |

全部数据**零网络下载**（合成或 sklearn 内置）。训练池 / 测试集按 0.7 / 0.3 分层切分，测试集独立不参与任何查询或拟合。

## 3. 组成与超参

- 学习器：`RandomForestClassifier(n_estimators=60, random_state=0, n_jobs=1)`（可切 `lr` / `xgb` / `lgbm`）
- 策略：random / uncertainty(entropy) / committee(BALD, 5 成员) / coreset(k-center) / hybrid(批感知)
- 默认预算：`budget_frac=0.2`、`batch_frac=0.03`、`init_per_class=2`
- seeds：`[42, 123, 777]`

## 4. 指标（3 seeds，mean ± std，标签预算 20%）

| dataset | random | best active | Δacc | 显著 |
|---------|--------|-------------|------|------|
| gaussian2d | 0.711 ± 0.016 | 0.754 ± 0.027 (coreset) | +0.043 | ✅ |
| moons | 0.861 ± 0.017 | 0.886 ± 0.002 (committee) | +0.025 | ✅ |
| blobs20 | 0.670 ± 0.008 | 0.721 ± 0.009 (uncertainty) | +0.051 | ✅ |
| spiral | 0.594 ± 0.013 | 0.615 ± 0.015 (hybrid) | +0.021 | ✅ |
| digits700 | 0.873 ± 0.009 | 0.932 ± 0.016 (uncertainty) | +0.059 | ✅ |

聚合：平均 Δacc = **+0.0396**，5/5 数据集通过显著性门槛（Δ > 0.5×(std_a+std_r)）。

## 5. 局限

1. **策略与数据形态强相关**：没有通吃策略。`uncertainty` 在 `spiral` 上反劣 -0.039，`coreset` 在 `moons` 上几乎无增益 +0.001。上线前必须在目标数据上做策略选择。
2. **数据过易时无收益**：随机已逼近天花板时（如 sep=4.0，Δ=+0.003）主动查询边际收益趋零甚至为负。
3. **高维原始特征下几何多样性退化**：`coreset` 在 64 维像素特征上效果弱于不确定性类策略，建议改用嵌入空间。
4. **冷启动**：种子标注极少（每类 ≤2）时不确定性估计不可靠；建议先用随机/核心集播种再切换策略。
5. **标签噪声**：不确定性采样优先选择「最难」样本，若标注本身含噪声，误标影响会被放大（本基准未注入噪声，属未验证风险）。
6. **学习器耦合**：结论基于 RF(60)；换用更强/更弱学习器时增益幅度会变化（实测 RF 40 树时增益降至 0.0282）。

## 6. 公平性与安全

- 本系统为**算法框架**，不含预训练模型，无训练数据偏差引入。
- 若应用于人员相关决策场景，需自行评估标注成本分配与样本代表性偏差（主动采样会系统性地偏向边界样本，池的类别分布可能与真实分布不同）。

## 7. 复现

```bash
python -m activeforge.cli bench --out benchmark.json
```

固定 seed，两次运行除 `elapsed_sec` 外逐位一致。
